# Landing Page Profissional Responsiva

## Sobre o projeto
Este projeto consiste em uma Landing Page Profissional Responsiva desenvolvido como atividade acadêmica.

## Tecnologias utilizadas
- HTML5: estrutura da página.
- CSS3: estilização da página.
- JavaScript: funcionalidades e interatividade.

## Objetivo
Aplicar conhecimentos de desenvolvimento Front-End na criação de uma página web responsiva e rica em funcionalidades.
